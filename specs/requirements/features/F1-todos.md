# Todos

## Purpose

A signed-in user adds todos and marks them done.

## User Stories

- F1.1 As a user, I add a todo by typing a short text title.
- F1.2 As a user, I see all my todos in one list, newest first.
- F1.3 As a user, I mark a todo as done.
- F1.4 As a user, I see done todos stay in the list, shown as done.

## Decisions

- A todo is a short text title only; no description.
- Done is final: a done todo cannot be marked not done again.
- A todo cannot be added with an empty title.
